# Enterprise AgentOps Platform

Enterprise-grade AI agent platform for production incident
investigation, root-cause analysis and controlled remediation.

## Goals

- Multi-agent orchestration
- RAG
- MCP-based tool integration
- A2A agent communication
- Human-in-the-loop remediation
- AI evaluation
- AI observability
- Agent security
- Durable workflows
- Multi-tenancy
- AWS/Kubernetes deployment
